# Aula de IA — Classificação com scikit-learn

Trabalho para a matéria de Inteligência Artificial no curso de Sistemas de Informação: treino e comparação de modelos de classificação (Decision Tree, Random Forest, entre outros) sobre um dataset baixado via `kagglehub`, com pré-processamento (encoding, escalonamento) e avaliação por acurácia e matriz de confusão.

## Conteúdo

- `steam.py` — carregamento, pré-processamento e treino dos modelos
- `comparacao_acuracia.png` — gráfico comparativo dos resultados

## Stack

- Python, pandas, scikit-learn, seaborn/matplotlib

Trabalho de faculdade — Inteligência Artificial.
